# nu_plugin_ipscan documentation

This directory contains the Astro Starlight documentation site for
`nu_plugin_ipscan`, including the generated Rust API reference for the standalone
`ipscan` implementation and the Nushell adapter.

## Structure

```text
.
├── public/rustdoc/       # generated by `npm run rustdoc`
├── src/
│   └── content/docs/     # Starlight pages
├── astro.config.mjs
├── scripts/
│   └── build-rustdoc.mjs
├── package.json
└── tsconfig.json
```

## Local development

Install the locked JavaScript dependencies and start the site:

```sh
npm ci
npm run dev
```

`npm run dev` regenerates the embedded Rustdoc before starting Astro.

Build the complete static site, including fresh Rustdoc:

```sh
npm run build
```

The production output is written to `dist/`. The build requires Cargo and a
Rust toolchain because `prebuild` regenerates both the `ipscan` and
`nu_plugin_ipscan` references first.
